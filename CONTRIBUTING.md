# Contributing to Diagnelia

Thank you for your interest. Diagnelia is at an early stage, so most help today is feedback, corrections and ideas.

## Where to write

| Repository | Best way to help |
|---|---|
| [responsible-ai](https://github.com/diagnelia/responsible-ai) | Open an issue with questions or suggestions about how the AI should behave |
| [diagnelia-website](https://github.com/diagnelia/diagnelia-website) | Open an issue for a broken link, a typo or a translation problem in English, German or Ukrainian |
| [brand-assets](https://github.com/diagnelia/brand-assets) | Issues are off. Email info@diagnelia.com for brand questions or permission to use the logo |
| Anything else | Email info@diagnelia.com |

Clinicians, geneticists, patient organisations and researchers who want to help shape or pilot the product are welcome to write to info@diagnelia.com.

## Rules for issues

- One problem or idea per issue, with a clear title.
- Search existing issues first.
- **Never include real personal or medical data.** Use invented examples only.
- Do not report security problems in issues. See [SECURITY.md](SECURITY.md).

## Pull requests

Small pull requests are welcome, for example a typo or a translation fix. For anything larger, please open an issue first so we can agree on the change.

By taking part you agree to our [Code of conduct](CODE_OF_CONDUCT.md).
